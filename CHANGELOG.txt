Muted 0.2.0 — October 24, 2026

- Renamed to Muted across the interface, tooltips, JSON export, and new packages.
  No tagline in the app; existing settings remain compatible.
- Individual tab errors appear only in the affected page's popup. The icon
  continues to show on/off/pause; warnings remain for missing permissions and fundamental errors.
- Both modes share a single, explicitly requested HTTP/HTTPS access grant.
  Lists and mode control the filter rather than browser permissions.
- Removed permission management from settings. An access prompt appears only
  when permissions are missing. Existing UX improvements are retained.
- Older lists, on/off settings, pauses, and JSON exports remain compatible;
  the intended result of an interrupted older permission cleanup is also migrated.
- Status and document decisions use loaded state without repeated browser queries.
  Tab events affect individual tabs; tabs already reconciled are not reinjected on activation.
- Worker wake-up does not query all tabs when registration is unchanged.
  New registration and expired pauses reconcile existing pages.
- Popup/settings receive change notifications instead of polling periodically.
- Protection against sleeping tabs, stale activations, and permission loss remains.
- Develop directly from extension/; packaging is optional, with ZIP creation only via --zip.
  Comprehensive manual acceptance testing is not required for personal use.

Muted 0.1.1 — October 24, 2026 — Test candidate

- Fixed: an injection waiting on a frozen tab blocked the shared worker queue.
  The popup remained at "Please wait" and new pages received no filtering decision.
  Reproduced in Edge with exactly one frozen tab; verified after the fix in Edge and Chrome.
- Tab reconciliation waits outside the state queue. New reconciliation requests
  are merged; stale results are not published.
- Individual tab operations have time limits. Tabs reported as sleeping/discarded
  are not woken; activation/wake-up triggers reconciliation.
- Delayed activations check the current worker state when they actually execute.
  An older enabled state cannot reactivate the filter after it has been turned off.
- The popup refreshes pending confirmations and shows a status for sleeping tabs.
- Four additional regression tests, 27 passing in total. Native consent in the
  personal Edge profile was still awaiting another manual check at this stage.

Muted 0.1.0 — October 24, 2026 — Test candidate

- Local Manifest V3 runtime with no external dependencies or network functions.
- Global/selected modes with independent domain lists and optional host permissions.
- Persistent on/off setting, absolute pause deadlines, and alarm restoration.
- Serialized worker, persistent revisions, and resumable permission cleanup.
- Idempotent isolated controller, root CSS, and limited observers.
- German popup, settings, permission display, import preview, and Blob export.
- TDD with the Node test runner and browser API doubles; partial real-browser checks in Edge/Chrome.
- Full native browser acceptance testing still pending; no automatic installation.
