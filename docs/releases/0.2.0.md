# Muted 0.2.0

First GitHub release of Muted, a grayscale extension for Chrome and Edge.

## Features

- Apply grayscale to all websites with exceptions, or only to selected websites.
- Change the current website's rule from the toolbar popup.
- Pause grayscale for 5, 15, or 30 minutes.
- Import and export website lists as JSON.
- Use German or English controls, selected from the browser's language.

## Changes from 0.1.x

- Renamed the extension to Muted. Existing settings and JSON exports remain compatible.
- Both modes now use one explicitly requested grant of access to HTTP and HTTPS websites.
  Website lists control where grayscale is applied.
- Improved handling of sleeping tabs and delayed page updates.
- Removed periodic popup and settings polling.

## Install

1. Download the `muted-….zip` asset below.
2. Extract it into a folder you will keep on your computer.
3. Open `chrome://extensions` or `edge://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted `extension` folder.
6. Pin Muted, open its popup, and click **Allow access**.

No Git, Node.js, or build step is needed to install the extension.
The `.zip.sha256` asset contains the archive's SHA-256 checksum.

## Updates and limitations

Updates are manual. Replace the files at the existing loaded path, then click **Reload**
on Muted's card. See the [update instructions](https://github.com/stefanvictora/muted/blob/v0.2.0/docs/INSTALLATION.md#load-and-update).

Updating from 0.1.x preserves website lists, the on/off setting, and pauses. If access was
previously granted only to individual websites, click **Allow access** again.

Browser pages, extension stores, private windows, local files, and PDF viewers are not supported.
