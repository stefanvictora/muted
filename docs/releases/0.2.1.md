# Muted 0.2.1

## Fixes

- Remove a parent domain's rule directly from a subdomain's popup. The button is
  now available, and the note below it names the affected domains and explains
  that their subdomains are included.
- Color exceptions now show **Make gray again**. For example, on `docs.example.com`,
  you can remove the exception for `example.com` without opening Settings.
  In **Selected websites only** mode, **Keep in color** removes the inherited grayscale rule.
- If several rules include the current website, the popup removes them together.
  Other saved rules remain in place.

## Update

1. Download and extract the `muted-0.2.1-….zip` asset below.
2. Replace the contents of your currently loaded `extension` folder with the new
   package's `extension` contents, keeping the same path.
3. Open `chrome://extensions` or `edge://extensions` and click **Reload** on Muted's card.
4. Reopen the popup. If a website still uses the old filter, reload that website.

Existing settings remain compatible. See the [full update instructions](https://github.com/stefanvictora/muted/blob/v0.2.1/docs/INSTALLATION.md#load-and-update).
The `.zip.sha256` asset contains the archive's SHA-256 checksum.
