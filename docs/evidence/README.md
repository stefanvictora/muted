# Historical browser evidence

These JSON reports record earlier Chrome and Edge checks. Read them alongside
[the historical verification record](../VERIFICATION-0.1.x.md) for their scope and limitations.
The [0.2.0 verification record](../VERIFICATION.md) describes subsequent behavior and checks.

The descriptive `checks`, `scope`, and `permissionPrompt` captions have been translated
from German into English. Machine-specific extension IDs have been replaced with
`test-extension-id` for publication. Browser versions, timings, flags, error arrays,
and test outcomes are unchanged. These edits do not represent a new test run.
